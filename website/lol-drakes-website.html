  • NOT a cheat or hack

Frequently Asked Questions

Is this against Riot's ToS?

No. We only read game data that's publicly available through Riot's API. We don't interact with the game client or modify gameplay.

Is it really free?

Yes, completely free. We built this to learn and showcase our skills, not to make money.

How accurate is it?

Based on testing with Grandmaster+ game data, our predictions are ~85% accurate for objective outcomes.

Can I contribute to the project?

Yes! We're open to collaboration. Check our GitHub for open issues or contact us directly.
